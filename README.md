# 🛡️ TryHackMe Writeups

Welcome to my **TryHackMe Writeups** repository!

This repository contains my personal writeups for the machines and rooms I have completed on **TryHackMe**. The goal of this project is to document my learning process, reinforce offensive security concepts, and build a public knowledge base that may also help others preparing for penetration testing certifications such as **eJPT**, **eCPPT**, **PNPT**, or **OSCP**.

> **Disclaimer:** These writeups are intended for educational purposes only. They should only be used in legal environments and against systems you have permission to test.
